Risk Register

🔴 HIGH — Velocity oscillations at high Re

Impact: HIGH

Spatial oscillations visible in VTK output. Mesh tangling near sharp branch corners.

Mitigation:

Add SUPG (Streamline Upwind Petrov-Galerkin) stabilization to convective term. Use inverse-volume Laplacian ALE mesh stiffening.

🔴 HIGH — Added-mass instability (FSI)

Impact: HIGH

ρ_fluid ≈ ρ_solid (1060 vs 1100 kg/m³). Partitioned FSI inherently unstable at this density ratio.

Status: Mitigated via zero-order predictor + small time step (DT=2.5e-4 s).

Monitor at longer integration windows. Consider monolithic solver (MFEM) for Phase 6.

⚠ MEDIUM — 2D geometry limitations

Impact: MEDIUM

Plane strain model: side branches bend as cantilevers instead of radial expansion. Sharp corners cause stress singularities.

Mitigation: Accepted for Phase 4. Upgrade to smooth 3D geometry in Phase 6.
